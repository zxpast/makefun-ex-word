## The entry

One word — the word my ex would use to describe me:

> **voicemail**

She stopped calling because talking to me was like leaving a voicemail:
a message recorded, never answered, never called back. A self-own, not an
insult aimed at her — the narrator is the butt of the joke.

## How it works

`main.ts` (Node 22, stdlib only) is a constant-writer: it writes the single
word to `/output/entry.txt` with no trailing newline — exactly one word and
nothing else. It is deterministic (no network, no date, no randomness) and
includes a self-check enforcing the competition gate: UTF-8 text, 1–24
characters, not only whitespace, exactly one word.

Run it:

```sh
node main.ts
```
